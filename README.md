# 📚 Acervo biblioteca virtual Theka (Front-End) 

A biblioteca virtual Theka foi desenvolvida como desafio para a etapa de treinee na Empresa Junior da Escola de Ciência e Tecnologia da UFRN (EJECT/UFRN). O objetivo da biblioteca é apresentar um espaço para que seus usuários conheçam diversos livros através de um abundoso catálogo com novidades publicadas semanalmente!
